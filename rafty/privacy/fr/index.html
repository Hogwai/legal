Politique de confidentialité

Rafty · 16 mars 2026

Rafty est une application de navigation flottante pour Android développée par Hogwai. Toutes vos données restent sur votre appareil. Nous ne collectons, ne transmettons ni ne stockons aucune information personnelle.

Données stockées localement

Toutes les données sont stockées exclusivement sur votre appareil. Rafty ne transmet aucune donnée personnelle vers un serveur.

Donnée Détails Contrôle utilisateur
Historique de navigation URL, titre, favicon, horodatage Le mode incognito désactive l'enregistrement ; peut être effacé dans l'application
Favoris URL, titre, favicon, note optionnelle Supprimables dans l'application
Sessions sauvegardées URL, titre, favicon, position Pour la restauration de session ; effacées à la fermeture
Préférences utilisateur Moteur de recherche, position des bulles, opacité, options d'interface, etc. Configurables dans les Paramètres
Données WebView Cookies, localStorage, stockage DOM des sites visités Gérées par Android WebView

Rafty exclut explicitement toutes les données de l'application de la sauvegarde cloud Android et du transfert d'appareil. Vos données restent uniquement sur votre appareil.

Transmissions réseau

Transmission Destination Données utilisateur envoyées
Navigation web Sites visités par l'utilisateur Requêtes HTTP(S) standard (non collectées par Rafty)
Mise à jour des hôtes de blocage publicitaire GitHub (StevenBlack/hosts) Aucune (requête GET anonyme, tous les 7 jours)
Achat premium Google Play Billing API Géré entièrement par Google Play
Avis dans l'application Google Play Review API Géré entièrement par Google Play
Vérification des mises à jour Google Play Update API Géré entièrement par Google Play

Données non collectées

Rafty ne collecte, ne transmet et ne traite aucune des données suivantes :

  • Analytique ou télémétrie
  • Rapports de plantage
  • Données publicitaires ou interactions avec des régies publicitaires
  • Comptes utilisateur ou identifiants d'authentification
  • Identifiants d'appareil (Android ID, identifiant publicitaire)
  • Données de géolocalisation
  • Suivi inter-applications
  • Données partagées avec des tiers

Vos droits (RGPD)

En vertu du Règlement Général sur la Protection des Données (RGPD), vous disposez des droits suivants :

  • Droit d'accès : toutes les données sont visibles directement dans l'application
  • Droit de suppression : l'historique et les favoris peuvent être supprimés dans l'application ; la désinstallation supprime toutes les données
  • Droit à la portabilité : les données sont stockées localement sur votre appareil

Rafty n'exploitant aucun serveur, il n'y a aucun traitement de données de notre côté et aucun accord de traitement des données ne s'applique.

Permissions

Rafty demande les permissions Android suivantes :

Permission Objectif
SYSTEM_ALERT_WINDOW Afficher les bulles flottantes par-dessus les autres applications
INTERNET Charger les pages web dans le navigateur
ACCESS_NETWORK_STATE Vérifier la disponibilité du réseau pour les mises à jour du bloqueur de publicités
FOREGROUND_SERVICE Maintenir le service d'overlay en fonctionnement
FOREGROUND_SERVICE_SPECIAL_USE Service de premier plan pour l'overlay flottant (requis sur Android 14+)
POST_NOTIFICATIONS Afficher la notification du service de premier plan
REQUEST_IGNORE_BATTERY_OPTIMIZATIONS Exemption optionnelle de l'optimisation de batterie
RECEIVE_BOOT_COMPLETED Démarrer automatiquement la notification de recherche après le redémarrage de l'appareil

Protection des mineurs

Rafty ne s'adresse pas aux enfants de moins de 13 ans (COPPA) ni de moins de 16 ans (RGPD). L'application ne collecte pas sciemment de données concernant des mineurs.

Conservation des données

Toutes les données sont stockées localement sur votre appareil et persistent jusqu'à ce que vous les supprimiez explicitement (via les contrôles de l'application) ou que vous désinstalliez l'application. Rafty ne dispose d'aucun stockage côté serveur : il n'y a donc aucune durée de conservation gérée par le développeur.

Services tiers

Rafty intègre les services tiers suivants, chacun régi par sa propre politique de confidentialité :

  • Google Play Billing (achat premium) : Politique de confidentialité de Google
  • Google Play In-App Review : Politique de confidentialité de Google
  • Google Play In-App Update : Politique de confidentialité de Google
  • StevenBlack/hosts (liste de blocage publicitaire) : projet open source sur GitHub

Contact

Pour toute question relative à la confidentialité, veuillez nous contacter via notre formulaire de contact.

Modifications de cette politique

Nous pouvons mettre à jour cette politique de confidentialité. Les modifications seront communiquées via les notes de mise à jour de l'application, et la date d'entrée en vigueur en haut de cette page sera mise à jour en conséquence.
