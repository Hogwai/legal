Politique de confidentialité

StockExtremis · 26 mars 2026

StockExtremis est une application de gestion de stocks et de suivi des dates de péremption pour Android, développée par Hogwai. Vos données produit restent sur votre appareil. Nous ne collectons que les données minimales nécessaires au contrôle d'accès de la version d'évaluation.

Données stockées localement

Toutes les données produit et utilisateur sont stockées exclusivement sur votre appareil via une base de données locale et des préférences. StockExtremis ne transmet pas vos données produit vers un serveur.

Donnée Détails Contrôle utilisateur
Produits et lots Nom du produit, code-barres, image, date de péremption, statut, champs personnalisés Peuvent être ajoutés, modifiés et supprimés dans l'application
Catégories et marques Catégories et marques créées par l'utilisateur pour organiser les produits Gérables dans l'application
Préférences utilisateur Thème, langue, paramètres de notification, planification des rappels Configurables dans les Paramètres
Images produit Photos prises ou importées pour les produits, stockées dans le stockage privé de l'application Supprimées lorsque le produit associé est retiré

Services Firebase (versions d'évaluation uniquement)

Les versions d'évaluation de StockExtremis utilisent les services Firebase pour le contrôle d'accès. Les versions de production n'utilisent pas Firebase.

Service Objectif Données collectées
Firebase Firestore Enregistrer l'installation et vérifier l'autorisation d'accès ID d'installation Firebase, modèle d'appareil, version de l'application, horodatage du dernier check-in
Firebase Installations Générer un identifiant d'installation unique et anonyme ID d'installation (non lié à des informations personnelles)
Firebase Analytics Dépendance requise pour Firebase ; la collecte automatique est désactivée Un seul événement personnalisé (eval_install) enregistré au premier lancement uniquement

L'ID d'installation Firebase est un identifiant anonyme généré aléatoirement. Il n'est pas lié à votre compte Google, numéro de téléphone, e-mail ou toute autre information personnelle. Le développeur peut désactiver l'accès à une installation spécifique à distance.

Transmissions réseau

Transmission Destination Données utilisateur envoyées
Recherche de produit par code-barres API Open Food Facts Numéro de code-barres uniquement ; requête anonyme avec User-Agent de l'application
Vérification d'accès évaluation Google Firebase (Firestore) ID d'installation, modèle d'appareil, version de l'application (versions d'évaluation uniquement)
Achat premium Google Play Billing API Géré entièrement par Google Play

Données non collectées

StockExtremis ne collecte, ne transmet et ne traite aucune des données suivantes :

  • Sessions utilisateur, rétention ou analytique comportementale
  • Rapports de plantage
  • Données publicitaires ou interactions avec des régies publicitaires
  • Comptes utilisateur ou identifiants d'authentification
  • Identifiants personnels (nom, e-mail, numéro de téléphone)
  • Données de géolocalisation
  • Suivi inter-applications
  • Données produit transmises vers un serveur (restent sur l'appareil)

Vos droits (RGPD)

En vertu du Règlement Général sur la Protection des Données (RGPD), vous disposez des droits suivants :

  • Droit d'accès : toutes les données produit sont visibles directement dans l'application ; l'ID d'installation Firebase est affiché dans la page À propos
  • Droit de suppression : toutes les données locales peuvent être supprimées dans l'application ou en désinstallant ; l'enregistrement Firestore peut être supprimé sur demande
  • Droit à la portabilité : les données peuvent être exportées en CSV via la fonction d'export de l'application

Permissions

StockExtremis demande les permissions Android suivantes :

Permission Objectif
INTERNET Recherche de code-barres via Open Food Facts ; vérification d'accès Firebase (évaluation uniquement)
ACCESS_NETWORK_STATE Vérifier la disponibilité du réseau
CAMERA Scanner les codes-barres avec la caméra de l'appareil
POST_NOTIFICATIONS Afficher les notifications de rappel de péremption
SCHEDULE_EXACT_ALARM / USE_EXACT_ALARM Planifier des notifications de rappel précises
RECEIVE_BOOT_COMPLETED Replanifier les rappels après le redémarrage de l'appareil
REQUEST_IGNORE_BATTERY_OPTIMIZATIONS Exemption optionnelle de l'optimisation de batterie pour des rappels fiables

Protection des mineurs

StockExtremis ne s'adresse pas aux enfants de moins de 13 ans (COPPA) ni de moins de 16 ans (RGPD). L'application ne collecte pas sciemment de données concernant des mineurs.

Conservation des données

Toutes les données produit sont stockées localement sur votre appareil et persistent jusqu'à ce que vous les supprimiez explicitement ou que vous désinstalliez l'application. Pour les versions d'évaluation, l'enregistrement Firestore persiste jusqu'à suppression manuelle par le développeur. Aucune autre donnée côté serveur n'est conservée.

Services tiers

StockExtremis intègre les services tiers suivants, chacun régi par sa propre politique de confidentialité :

  • Open Food Facts (recherche de produits) : Conditions d'utilisation
  • Google Firebase (contrôle d'accès évaluation) : Confidentialité Firebase
  • Google Play Billing (achat premium) : Politique de confidentialité de Google

Contact

Pour toute question relative à la confidentialité, veuillez nous contacter via notre formulaire de contact.

Modifications de cette politique

Nous pouvons mettre à jour cette politique de confidentialité. Les modifications seront communiquées via les notes de mise à jour de l'application, et la date d'entrée en vigueur en haut de cette page sera mise à jour en conséquence.
