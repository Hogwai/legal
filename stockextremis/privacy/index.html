Privacy Policy

StockExtremis · Effective March 26, 2026

StockExtremis is a stock management and expiration tracking app for Android developed by Hogwai. Your product data stays on your device. We only collect minimal data necessary for the evaluation version’s access control.

Data Stored Locally

All product and user data is stored exclusively on your device using a local database and preferences. StockExtremis does not transmit your product data to any server.

Data Details User Control
Products & batches Product name, barcode, image, expiration date, status, custom fields Can be added, edited, and deleted in-app
Categories & brands User-created categories and brands for product organization Can be managed in-app
User preferences Theme, language, notification settings, reminder schedules Configurable in Settings
Product images Photos taken or imported for products, stored in app-private storage Deleted when the associated product is removed

Firebase Services (Evaluation Builds Only)

Evaluation builds of StockExtremis use Firebase services for access control. Production builds do not use Firebase at all.

Service Purpose Data Collected
Firebase Firestore Register the installation and check access authorization Firebase Installation ID, device model, app version, last check-in timestamp
Firebase Installations Generate a unique, anonymous installation identifier Installation ID (not linked to any personal information)
Firebase Analytics Required dependency for Firebase; automatic collection is disabled One custom event (eval_install) logged on first launch only

The Firebase Installation ID is an anonymous, randomly generated identifier. It is not linked to your Google account, phone number, email, or any other personal information. The developer can disable access to a specific installation remotely.

Network Transmissions

Transmission Destination User Data Sent
Product lookup by barcode Open Food Facts API Barcode number only; anonymous request with app User-Agent
Eval access check Google Firebase (Firestore) Installation ID, device model, app version (eval builds only)
Premium purchase Google Play Billing API Handled entirely by Google Play

Data Not Collected

StockExtremis does not collect, transmit, or process any of the following:

  • User sessions, retention, or behavioral analytics
  • Crash reports
  • Advertising data or ad network interactions
  • User accounts or authentication credentials
  • Personal identifiers (name, email, phone number)
  • Geolocation data
  • Cross-app tracking data
  • Product data transmitted to any server (stays on device)

Your Rights (GDPR)

Under the General Data Protection Regulation (GDPR), you have the following rights:

  • Right of access: all product data is visible directly in the app; the Firebase Installation ID is displayed in the About page
  • Right of deletion: all local data can be deleted in-app or by uninstalling; the Firestore installation record can be deleted on request
  • Right of portability: data can be exported to CSV via the app’s export feature

Permissions

StockExtremis requests the following Android permissions:

Permission Purpose
INTERNET Barcode lookup via Open Food Facts; Firebase access check (eval only)
ACCESS_NETWORK_STATE Check network availability
CAMERA Scan barcodes using the device camera
POST_NOTIFICATIONS Display expiration reminder notifications
SCHEDULE_EXACT_ALARM / USE_EXACT_ALARM Schedule precise reminder notifications
RECEIVE_BOOT_COMPLETED Reschedule reminders after device restart
REQUEST_IGNORE_BATTERY_OPTIMIZATIONS Optionally exempt from battery optimization for reliable reminders

Children’s Privacy

StockExtremis is not directed at children under 13 (COPPA) or under 16 (GDPR). The app does not knowingly collect data from children.

Data Retention

All product data is stored locally on your device and persists until you explicitly delete it or uninstall the app. For evaluation builds, the Firestore installation record persists until manually deleted by the developer. No other server-side data is retained.

Third-Party Services

StockExtremis integrates the following third-party services, each governed by their own privacy policies:

  • Open Food Facts (product lookup): Terms of Use
  • Google Firebase (eval access control): Firebase Privacy
  • Google Play Billing (premium purchase): Google Privacy Policy

Contact

For privacy-related inquiries, please reach out via our contact form.

Changes to This Policy

We may update this privacy policy from time to time. Changes will be communicated via app update notes, and the effective date at the top of this page will be updated accordingly.
